# 单元 0 · 解题引擎（讲义）

> 学习时长：1 个 session（约 50 分钟：读本讲义 20 分钟 + 3 道示范跟着算 10 分钟 +
> 做摸底卷 22 分钟）。摸底卷在《单元0_自编摸底卷.md》，**先做完再看答案文件**。

## 一、先立规矩：你是来"选"的，不是来"解"的

考场现实：地市卷 10 题只给 10 分钟（含涂卡），单题预算 **50–70 秒**。硬算一道二元方程
的时间够你用快法做两道。而国考数量近一半的题，题干里埋着"不用算完"的钩子。

**每道题按顺序问自己三个问题，全都不行才列方程（且只许一元一次）：**

1. **能不能不设未知数？**——整除/倍数/奇偶/尾数（板斧一）
2. **能不能把选项代回去？**——代入排除（板斧二）
3. **能不能只设"份"不设"数"？**——赋值/设份数（板斧三）

## 二、板斧一：数字特征排除（不动笔）

| 信号词 | 钩子 | 操作 |
|---|---|---|
| "每 X 个一份""平均分""正好装完" | 结果被 X 整除 | 排除不含因子的选项 |
| "A 是 B 的 a/b"（a/b 最简） | B 是 b 的倍数，A 是 a 的倍数 | 先锁候选集 |
| "A 比 B 多/少 x%" | 化分数：x%→分数→倍数关系 | 转成上一行 |
| 和差问题 | 和差同奇偶 | 排一半选项 |
| 多数连乘/连加 | 看尾数 | 只算个位 |
| 选项间隔大 / 区间型 | 允许估算 | 算数量级即可 |

**要点：单个百分数只给候选集，两个条件（双钩）才能锁死答案。**

> 微型感受（尾数钩）：要算 44×37−118，四个选项尾数各不相同时只算个位——
> 4×7−8=20 → 个位是 0，10 秒锁定。（奇偶钩：和差同奇偶、乘式有偶则偶，
> 常用于最后二选一时仲裁。）这两类钩子在后续单元练习中会大量出现。

### 示范 1（双整除钩）[2013·合卷·73]
> 两派出所月共受理 160 起，甲所 17% 是刑事案件，乙所 20% 是刑事案件，问乙所受理多少起非刑事案件？
> A. 48　B. 60　C. 72　D. 96

（先自己试 20 秒，再看下面。）

17% = 17/100 → 甲受理总数是 **100 的倍数**；20% → 乙是 **5 的倍数**。两者和为 160，
甲≥100 → 只能甲=100、乙=60 → 乙非刑事 60×80% = **48，选 A**。
常规解法要设两个未知数解方程（约 90 秒），快法 40 秒、零方程。

### 示范 2（赋值）[2012·合卷·66]
> 一、二季度降水量同比分别增 11% 和 9%，两个季度**绝对增量相同**，问上半年同比增长多少？
> A. 9.5%　B. 10%　C. 9.9%　D. 10.5%

增量相同 → 把增量赋为 99（11 和 9 的公倍数）：一季度去年 900、二季度去年 1100。
增长 198 ÷ 去年共 2000 = **9.9%，选 C**。谁大谁小一眼可判：增长率必然夹在 9% 和 11%
之间且偏向基数小的那侧——连 99 都可以不赋。

### 示范 3（整除直选）[2011·合卷·69]
> 去年 830 人，今年男员工减 6%、女员工增 5%，总数增 3 人，问今年男员工多少人？
> A. 329　B. 350　C. 371　D. 504

男减 6% → 今年男 = 去年男 × 94% = ×47/50 → **今年男是 47 的倍数**。选项中只有
329 = 47×7。**选 A**，15 秒，不用碰"女员工"的条件。

## 三、板斧二：代入排除（选项即线索）

适用：年龄、余数分组（盈亏）、不定方程、"至少/最多"类、**比例关系式验证**。
操作：**优先代中间选项**（B 或 C），结果偏大→往小的代，偏小→往大的代，一次定位。

### 示范 4（代选项验比例）[2013·合卷·64]
> 乙型产量的 3 倍与丙型产量的 6 倍之和等于甲型产量的 4 倍；甲型产量与乙型产量的 2 倍之和等于丙型产量的 7 倍。问甲:乙:丙？
> A. 5︰4︰3　B. 4︰3︰2　C. 4︰2︰1　D. 3︰2︰1

直接代选项（比例题的选项本身就是份数，代哪个都等价，可挑数字最小的代）：代 D（3:2:1）
→ 3×乙+6×丙 = 6+6 = 12 = 4×甲 = 12 ✓；再验 甲+2×乙 = 3+4 = 7 = 7×丙 ✓ → **选 D**。
10 秒，连"份"都不用设。（一般数值题仍按"先代中间选项"操作，见下一示范的方向反馈。）

### 示范 5（代年龄）[2015·副省·64]
> 弟比小李小 2 岁；王的哥哥比王大 2 岁、比小李大 5 岁；1994 年弟+王=15 岁；问 2014 年小李、王的年龄分别是多少？
> A. 25，32　B. 27，30　C. 30，27　D. 32，25

代中间 C（小李30，王27）：弟=28、哥=29，哥−小李 = 29−30 = −1 ≠ +5 → 小李**偏大**
→ 往小的代 B（小李27，王30）：弟25、哥32 → 哥−小李=5 ✓；1994 年（各减 20）：
弟5、王10 → 和 15 ✓ → **选 B**。注意：第一次代错了不是失败——它告诉你方向。正面列方程要 4 个未知量，代入只要会算术。

## 四、板斧三：赋值与设份数（消灭未知数）

- **总量未知**（工程/行程/混合）→ 赋成各份量的公倍数，或干脆赋总量=1；
- **全是比例**（速度比、效率比、人数比）→ 设"1 份"，**最后用比例消掉它，不求出它**；
- **单价/成本未知** → 赋 100（经济题默认动作）。
- 口诀：**未知数出现在"比"里，就不配拥有名字——它叫"份"。**

## 五、20 秒决策流程 + 战场纪律

```
读题（20秒，同步扫选项）
 ├─ 有整除/奇偶/尾数钩？ → 走板斧一
 ├─ 结构适合代选项？     → 走板斧二
 ├─ 全是比例/总量未知？  → 走板斧三
 └─ 都不行 → 标记跳过（单题2分钟封顶）
```

1. **跳过的题**最后统一蒙同一个字母（选本卷出现次数最少的选项，正确率不会低于
   乱蒙的 25%，且避免扎堆）。
2. 排除掉 2 个选项后剩 2 选 1：值得花 40 秒在两者之间做"量级/奇偶"仲裁，别空着。
3. 每做完一题自问一句：**我刚才走的是快路还是硬路？** 摸底卷要统计这个比例。
4. 单位（万元/亿、米/千米）和"多/少""甲比乙/乙比甲"是回忆版与自编题共同的头号陷阱，
   读题时就圈出来。
