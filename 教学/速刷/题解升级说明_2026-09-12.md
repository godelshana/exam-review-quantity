本轮目标：解决"GPT 式题解不是人话"的问题——先逐题独立复算答案，再全部重写为老师讲题风格的完整题解，并清理页面上的自述性废话。

- **独立重解**：全部 1238 题（真题 1105 + 原创 124 + GLM 9）由独立解题主理逐题"先做题、后对答案"，**与库内答案零分歧**。

## 二、题解重写（1226 题）

每题六个字段，全部重写为完整句子、不跳步的老师讲题风格：

| 字段 | 内容 |
|---|---|
| 考点与知识点 | 考点体系定位 + 本题知识点/公式 + 这类题的本质 |
| 方法一 · 常规解法 | 考场最稳做法，①②③分步，每步算式完整 |
| 方法二 · 快解 / 精简解法 | 与常规不同的更快路径，先讲原理再给步骤；无快路线的题诚实写"常规压缩版" |
| 方法三 · 排除法与选项分析 | 结合本题四个选项的整除/倍数/尾数/量级/选项关系排除，或最短代入验证 |
| 易错点 | 具体到"看错哪个字眼、会错选哪项、为什么" |
| 换一条路复核 | 与两法不同的第三条独立核算路径，完整算式 |

- 选项字母一律用 `[[option:X]]` 占位符（原创题选项乱序时自动重映射）。
- 争议题按给定答案写主推导，分歧观点如实呈现在易错点/复核中，并建议粉笔/华图核对。
