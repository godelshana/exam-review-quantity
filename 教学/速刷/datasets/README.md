# 数量关系数据层（离线可重建）

## 构建与门禁

```powershell
python 教学/速刷/build_datasets.py
python 教学/速刷/build_datasets.py --check
python 教学/速刷/test_datasets.py
```

默认构建只读本目录 `sources.json`、`certificates.json` 和 `../build_datasets.py`，不依赖未跟踪的 `真题库/`、`_downloads/`、网络、第三方 Python 包。`--check` 不写文件。测试包含 Node/current core 联调，以及仅复制上述输入到临时目录的离线重建。

需要更新本地素材快照时才显式执行：

```powershell
python 教学/速刷/build_datasets.py --import-local
# 先人工审阅变更题干及模型；下面的生成命令不是自动证明新题正确。
python 教学/速刷/datasets/make_certificates.py
python 教学/速刷/build_datasets.py
python 教学/速刷/test_datasets.py
```

`make_certificates.py` 是逐题手写模型与教学路径的可读源。**不要在题面变化后未经审阅就重绑 sourceHash**。默认构建会拒绝旧证书：UID、元数据、题面、选项、来源答案、来源证据均参与绑定。改变脚本后须重新构建，因为 manifest 绑定生成器 LF SHA256。

## 浏览器接口

- `banks.js`：`window.DATASET_TRAIN`（只含可用训练题）、`window.DATASET_VALIDATION`（包含所有105槽位，必须经过资格过滤）、`window.DATASET_AUDIT_SUMMARY`。
- `authored_policy.js`：`window.DATASET_AUTHORED_OVERRIDES` 是 **UID → 对象**。在原创124题原有数学/方法包装**之后**覆盖；这里只做模板泄漏筛查，不重新认证原创数学，不输出原创题库本体。
- `a` 是零基索引；隔离题/未复算题统一 `null`。来源答案另存 `sourceAnswer`，不把它当自动评分键。
- 可用题有 `sourceType=real|glm`，并提供专属快法、常规法、陷阱、边界、梯度等全部约定字段。
- `sourceQuestionUid=heldout:<year>:text:<digest>` 是保留验证题的稳定文本 identity；忽略排版标点但保留数字与运算关系，同年跨卷相同题干共用 identity。**30个可评分槽位只有21个不同 identity**，不能把跨卷复用题当独立首测。
- 本轮只有严格通过的 V1 或保守隔离 V3，**没有把未复算/争议题包装成 V2**。V3的题干用于清单与泄漏检查，不能进入练习计分。

## 数学与来源边界

- 独立计算指**不读取来源答案来求解**，由当前作者从原题建立精确分数、方程或穷举模型并核对唯一选项；不是另一个审查者的独立复审。常规模型包括完备域、约束、见证或回代检查；常规路径中的程序穷举是审计手段，不冒充考场快法。
- 80条计算模型通过，另1条等体积分割题被反例否定；计算通过不等于能发布。源答案冲突、缺图、历史争议、模板风险和同族去重还会拒收。现有合格训练35题＝旧国考26＋GLM9；验证V1 30槽位、V3 75槽位。
- 旧结构报告只覆盖287题且曾错误保留2021—2023作验证。本轮用多行解析补全旧题295条清单；**没有继承旧年份边界，也没有把旧结构报告当独立数学审计**。近三年固定2024—2026。
- `fastValue`、梯度为教学判断，未做考生群体耗时标定；正常列式不强称秒杀。
- 广东三年本地均无真实卷别目录、题面及可靠答案，`expectedSlots=null`。只报已收录0，不虚构应有题数或题面。广东边界仍严格保留；未来接入仍不得混入训练。

## 泄漏筛查边界

全文数字归一化相似度（0.72高、0.52中）结合明确的关系系统标签；不是仅截取前80字，也不是把“同属几何”一律判成同构。某些基础方法family采用保守拒收，风险标记不等于抄题认定。高/中风险均不自动进入普通训练；低风险仍须通过独立数学门禁。

本轮原创高10/中2/低112；GLM高13/低532。重要同构包括四部门调拨并入、逐题正分前缀、倒圆锥接圆柱恒流注水、连续课程块与不相邻休息日。所有候选对比范围包含V3可读题干，**不能靠验证题不可评分来绕过泄漏检查**。

`low` 仅表示**已收录国考范围**未命中规则；广东缺资料，无法保证对未知题零泄漏。完整语义同构识别仍有人审边界。该限制随逐题检查结果输出，不掩饰验证资料缺口。

## 收尾复审修复

- `glm:D:30` 原题保持“切成125等份”，不补成小正方体。125等体积薄片与5×5×5分割均满足题干，但无涂色块分别0与27。已记录 `mathAudit.status=failed` 并隔离。
- 2025副省76/执法72常规法已改为“折前/折后销量比4∶9，所以单件毛利比9∶4”，答案64%不变。
- V2统一定义为单列暂定成绩，不进入正式迁移指标；未满足可用资格不练。当前没有V2，不能据此把未复算题变成可评分题。
