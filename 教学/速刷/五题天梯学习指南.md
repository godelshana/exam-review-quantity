# 五题天梯：把“会做”练成“值得做、选得准”

> 这是给学习者的使用指南，不是算法说明。题目都是原创模拟，不是假称国考原题；阶段是教学预估，会随你的实际用时、错因继续调整。

## 一次只有五题，也要有一个小闭环

1. **第一套先盲做。** 初次从入门开始，选“整套后题解”；不要因为眼熟就抢答。你已经熟练时可直接选深化，不必强制打卡。
2. **先问要求，再看结构。** 要人数还是比例？最少还是恰好？至少还是至多？单位是小时还是分钟？把这四类词看清，比多背一个公式更值。
3. **找最便宜的入口。** 能否用总量、差量或比例？能否用整除、奇偶、范围排除？是否只需检验两个相邻选项？有入口再动笔，不要顺手把所有未知数都设出来。
4. **允许暂跳，但不把暂跳当答对。** 软时间目标不是自动交卷；长时间没有新增信息时先跳。复盘后再判断是“我尚不熟练”，还是“当前卷面里收益确实低”，不能只看题干长短。
5. **五题后逐题复盘。** 不仅看红绿，口头说一句：“看到____条件，我先____；但只有____成立才能这样做。”说不出这句，即使蒙对也要重练。

时间很碎时，只做一套并精看一个错点；不要为了凑题量省掉题解。页面支持导出当前浏览器记录，换手机暂不自动同步。

## 四阶到底增加什么

| 阶段 | 不只是“算得更大” | 达标时应能说清 |
|---|---|---|
| 入门 | 单模型、关键量、基本边界 | 为什么用这个分母？什么量没变？ |
| 熟练 | 基数变化、两步翻译、整数与区间 | 条件改变后，原来的公式还能直接用吗？ |
| 深化 | 两种工具配合，条件样本、分段、相似 | 第一层结果怎样交给第二层？哪一步不能省？ |
| 综合 | 多约束、离散可行性、过程限制 | 哪条约束最紧？上界是否真的能做到？ |

建议目标依次为35、55、75、100秒，不是所有考生都能做到的“秒杀承诺”。同阶至少10道不同题、最近最多20道不同题正确率至少80%、至少60%在目标内独立答对时，页面建议升阶。重复记住同一题答案不能凑够10题。看提示、暂停、标记猜测不算快速独立答对。

达到综合阶也不意味着每题都应该硬做：最后的迁移检验仍应回到限时真题。当前页面旧真题导入存在题面、图片和答案争议问题，暂不自动判分；请用项目内有来源标注的完整真题与解析，不要拿待核答案校准自己。

## 六个贯穿题型的本质抓手

### 1. 比例不是两个孤立数字，而是对同一个整体的切分

`challenge:001` 的站点调人，180人没有变，甲站所占份额从5/9变成9/20。比较份额后乘总量，直接得到调走人数；也可先算甲站前后100人、81人，差19人。两条路都短，哪条你更稳定就用哪条。

**触发条件：** 内部转移，总人数不变。**边界：** 若有人新加入或离开，总量已变，不能拿前后份额直接乘同一个总量。也不能直接用比例中的5和9相减。

### 2. 差量优先：共同部分往往不值得重复算

问涨价增加多少、合作相较原计划提前多少、调配后差额多少，先把共同部分消掉。差量解不是神秘技巧，本质是两条关系式相减。先确认“件数固定”或“总工作量相同”等成立，再用变化量反推。

**边界：** 单价、销量同时变化时，总额变化有交叉项；不能把两个百分比直接加起来。

### 3. 选项是额外信息，不是做完计算才看的装饰

选项都为整数，可先检查整除和余数；相隔很远，可先建立有保证的上下界；问最大可行数量，可尝试最大选项并核验约束。`challenge:002` 利用采购费用随产量不减，只需比较86套与87套的费用，找到可行与不可行的分界。

**边界：** “最大选项看起来差不多”不是证明。用边界选对，需要单调性；用估算排除，需要误差不跨过选项边界。选项接近、舍入敏感时应转为精算。

### 4. 整数约束的作用是删掉不可能，不是见到百分数就整除100

`challenge:024` 中，103吨用8吨与5吨两类车辆且都要使用，先写8a+5b=103，对5取余得到a≡1（mod 5），正整数范围内只剩a=1、6、11。不是把几十种组合逐一硬算。

**边界：** 只有题意明确人数、件数、整车满载等为整数时，整除才可用。标价有小数、百分比是近似值、车辆允许非满载时，不能照搬同余模型。旧GLM中“百分数出现，所以原价一定被100整除”的错误已经隔离。

### 5. “上界”与“能达到”必须成对出现

极值题可以先用总量和资源约束找天花板，再拿一个满足所有条件的安排去达到它。`challenge:008` 的分组题，上界不是终点，还要构造10、11、12、13、19这组人数，检查总和、互异和倍数约束全部成立。

**边界：** 连续计算得到13.8，向下取13只是候选；若存在整包、整日、互不相邻等限制，13仍可能不可行。反过来，找到一个方案也只证明“至少能这样”，未证明最优。

### 6. 守恒能贯穿阶段，速度和状态未必能

`challenge:015` 中水流体积速度恒定，锥体部分先用相似关系得到体积随高度的立方变化，再进入圆柱部分的线性变化。整个容器不能统一用“高度/时间”处理。

`challenge:011` 则要求答完每一步得分都严格大于零。最终总分合格并不保证中途合格；只需抓住下降后的风险节点检查，就比把所有时刻机械列一遍更省。

**共同点：** 先找在哪些时刻规则变化、约束可能失效，再分段。分段不是多写几条式子，而是避免把局部成立的规律推到全程。

## 错题不要只记“粗心”

| 错因 | 复盘时写什么 | 下一套怎样练 |
|---|---|---|
| 审题偏了 | 漏了哪个范围、单位、量词？ | 做题前用自己的话重说所求 |
| 模型选错 | 为什么误把等距离当等时间？ | 比较同题两种模型的适用条件 |
| 运算错了 | 哪步符号、分母、百分数出错？ | 优先用分数和约分，最后才转小数 |
| 边界漏了 | 整数、非空、最值是否可达？ | 每个候选答案代回全部约束 |
| 入口对但慢 | 多算了哪些题目根本没问的量？ | 读完题解，遮住答案重述最短链 |
| 答对但猜的 | 排除了哪些，剩余为何无法区分？ | 标记猜测，不把它当熟练证据 |

记录模板：`题目ID｜我用了什么入口｜实际卡点｜更短的一步｜这种方法的边界`。页面暂存选项、用时、提示和暂停等记录；这五项文字反思可以写进项目的错题本。

## 怎样防止记住数字却没学会

- 看完题解，先不抄算式，复述最短推理。
- 隔一段时间再做同结构的不同题，不立刻靠答案记忆冲正确率。
- 从“天梯”换到“跨阶混合”检验识别：没有题型标签时，还能找到入口吗？混合练习不冒充天梯升阶记录。
- 熟练后用可靠真题限时检验，不以模拟题正确率预测国考分数。
