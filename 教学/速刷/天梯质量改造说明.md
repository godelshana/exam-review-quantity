# 五题天梯质量改造说明

> 页面接入版本：2026-09-11。本文区分实现约定、数据审计结论和实际验收，不以“页面能打开”代替数学审计。

## 一、范围与默认行为

默认每轮5题，默认“训练混编天梯”：原创124题中符合当前可信协议的题，与经过数据层审计的旧真题 / GLM按阶混编。不是继续放行曾经初筛的104道GLM，更不回退545道全量旧库。

四个入口：训练混编天梯、迁移混编、最近三年验证首测、验证复盘。迁移混编优先每五题3训练+2验证，题池不足时按实际可用题调整。验证题只能为未曝光V1 / V2；V1正式、V2暂定单列。首测专用入口进一步只取V1。复盘仅取已曝光题。V3不可练。

2024—2026年国考、广东无论答案状态如何均不得进入训练。覆盖表逐年列接入数与V1/V2/V3数量；缺资料显示缺口，不生成占位练习题，也不声称国考理论105题或广东各卷已经全量齐备。详细覆盖与审计结果读 `DATASET_AUDIT_SUMMARY`，不把历史初筛数量写死为当前合格数量。

## 二、数据、方法与资格的责任边界

- 页面必须加载 `datasets/authored_policy.js` 的逐题原创隔离覆盖，覆盖124个UID且风险值合法；缺文件或缺项均fail closed，不改写旧存储。
- 页面加载 `datasets/banks.js` 的 `DATASET_TRAIN`、`DATASET_VALIDATION`、`DATASET_AUDIT_SUMMARY`。
- 原创以 `C.normalize(q)` 包装可信协议，合并 `AUTHORED_METHODS[q.uid]` 的专属方法，再合并 `DATASET_AUTHORED_OVERRIDES[q.uid]` 的隔离覆盖。隔离覆盖优先，不得被原创默认可信状态覆盖。
- 原创124题或专属方法资源缺失、core或数据集未加载时，显示错误并停用抽题；不修改旧存储，不偷偷回退旧库。方法缺失不等于可随便补一条“秒杀”。
- `C.sample` 总是收到完整bank：验证题元数据不得被UI先删掉，否则同构泄漏保护会失效。训练阶层 / 错题筛选可将排除训练题临时标为 `mathAudit: 'ui-excluded'`，保留所有验证元数据；数据层最终决定可练性。
- 抽样传入 `mode`、完整 `attempts`、`exposures` 和 `C.trainingMemory`。页面结果仅进一步收窄，不自行给未知题发训练资格。
- `source`逐题保存：`authored | glm | real`，不是给混编整轮贴同一个source。原创从已加载124题UID识别，GLM使用 `sourceType === 'glm'`，其余合格真题为real。

历史说明：GLM曾有104道“结构代表”，并不等于104道独立数学审计通过；545题去向仍可回看原筛选报告。旧54道内置样题、旧15道试编题及失败版百题不能恢复为加载失败的后备库。

## 三、首测不是可反复领取的标签

首测 = **本浏览器历史中未曝光**，不是保证学习者一生从未见过原题。页面不在首测前预览答案。

数据仍使用 `quantity-ladder-v3`、`schema: 3`；新增 `db.exposures: string[]`，旧记录缺失时由core兼容为空数组。身份由 `C.validationIdentity(q)` 给出（`sourceQuestionUid`优先，否则规范化题干），跨卷同题共享曝光资格。

流程：

1. `show`展示验证题前读取旧曝光 / 历史身份，确定本次 `firstValidation`。
2. 展示时立即把身份加入exposures并保存。首次身份判断不能在写入后才做。
3. 选择选项 / 暂跳才产生attempt，保存 `firstValidation`；未作答曝光不伪造attempt、不进入正确率。
4. 退出、刷新仍保留曝光；复盘模式显式 `firstValidation: false`。
5. 不截断历史验证记录 / 曝光数组，避免历史被裁掉后重获首测。存储不可写时禁用正式验证及迁移首测，并提示导出。

attempt保存：`dataset, exam, year, validationStatus, source, mode, firstValidation`，以及原题快照 `q`、选项映射、实际选择、耗时、提示 / 暂停 / 猜测等。异常旧数据由core.restore筛查，原始数据先备份后保存新库。

## 四、计时与题解

训练、验证复盘可提示和暂停；正式验证及迁移混编禁止两者，事件处理器也检查，不只是把按钮变灰。正式模式强制整轮后反馈，选项不即时着色、题型与入口不提前揭示。

正式时限为抽中各题目标时间之和；切换标签页仍按真实时钟计算，到时当前未答题记暂跳并结束。本轮未显示题不计曝光、不代答。训练目标时间35/55/75/100秒是建议值，不是官方考试时限，也不是考生群体实测。

逐题完整反馈展示：考点、最快路径、`normalPath`、`fastBoundary`、`skipDecision`、陷阱。专属方法覆盖与core的保守默认共同接入；缺失字段明确提示，不虚构不同解法。选项洗牌后只映射结构化选项引用，不误改“A产品/B机器”等对象名。支持题干 / 解析中的相对路径Markdown图片，转义HTML，不将远程或协议URL当本地图。

## 五、统计和晋级

`C.transferStats(rows, all)`提供训练、V1正式首测、重复 / 复盘、V2暂定四组，展示各组 `n / accuracy / fast`。迁移差为训练正确率减V1首测正确率，以百分点表示；样本不足显示不可计算，不预测考试得分。

验证题不影响训练记忆或晋级。迁移混编的训练题仍属于训练统计，但整轮不参与晋级；验证部分仍不增加训练权重。复盘不回填首次成绩。未作答曝光另列数量。

晋级只调用core训练规则：同阶最近最多20道不同题，至少10道，正确率≥80%，快速独立答对≥60%。提示、暂停、猜测不算快速独立；跨阶混编不晋级。手动换阶始终保留，门槛不是官方考试预测模型。

## 六、教学与审计不混为一谈

入门练单模型；熟练练基数、单位和整数边界；深化练两种工具衔接；综合练资源瓶颈、分段、离散可行性与上界构造。每题复盘“看到什么条件 → 选哪条路 → 哪一步能省 → 什么时候不能用”。

数学唯一答案、题面完整性、可信答案来源、解析与最快路径、层级和跳题收益应分别审计。程序断言不自动证明题面无歧义，页面代码更新不代表新数据逐题数学审计已完成。旧失败稿和审计快照保留回查。
