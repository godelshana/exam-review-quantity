# GLM 数量关系题库质量审查报告

> 审查对象：`教学/速刷/gen/gen_*_output.json`、对应生成脚本、`题库数据.js`。
> 审查日期：2026-09-09。

## 可执行结论

### 已确认可保留

1. 5个生成器输出合计 **545题**（A 130、B 100、C 125、D 110、E 80），不是54题。
2. 生成器普遍使用固定随机种子、选项洗牌和独立 checker/assert；重新运行生成脚本是答案一致性的基础验证。
3. 当前输出中跳过卡均为 `a=-1`，格式上与页面跳过逻辑一致。
4. 题干精确重复为0，但这不等于没有模板重复。

### 需要正视的问题

1. **模板重复明显**：按“题型+卡型+数字归一化题干”统计，存在大量同构变体；例如比例设份、概率正难则反、百分数反推、连续数列、估算乘法等。它们适合形成第一轮反射，但不能连续高密度刷，否则会记住句式。
2. **深钩/跳过的边界需要人工复核**：`gen_E.py` 的跳过卡集中在因数枚举、递推、分类计数、容斥、整型优化等高成本题，整体方向合理；但“能否通过选项代入在45秒内解决”仍需按真题标准抽查，不能仅凭生成器描述决定。
3. **解释文本存在可读性审查点**：数学记号 `等差数列{an}` 是合法文本，不应被误判为格式错误；审查器已将它列为白名单。后续若出现 `{d}`、`{x}` 等未展开占位符，应视为明确缺陷。
4. **题库质量不能只由 checker 证明**：checker 能证明参数化模型的答案，但不能证明题意自然、条件充分、选项有实战价值，亦不能发现“题目太像”的训练问题。

## 后续建议（按优先级）

1. **生成层增加模板配额**：同一模板签名每批最多8题；超出后换情境或降权，不要只换数字。
2. **刷题抽样层去同构**：一套5题中，同一模板最多1题；同一钩子最多2题，除非用户主动选择专项强化。
3. **跳过卡增加“选项收益”字段**：标记是否可代入、是否可估算、预计成本；可快速代入的题不得默认跳过。
4. **解释统一三句结构**：`最小模型` → `只算到能区分选项` → `陷阱/何时跳过`。目前很多解析是正确的短公式，但对学习者的迁移帮助不足。
5. **每批固定抽查**：每个生成器至少抽查10题，重点看题意充分性、选项干扰项是否来自真实错误路径、答案与解析是否一致；再用近年真题做迁移测试。
6. **答案可信度分层**：生成器 checker 通过只能标“参数校验通过”，不要在页面中显示成与真题同等可信度。

## 本次未直接修改题目

当前没有发现可以仅凭静态审查就安全批量改写的数学错误；直接改数字或答案会破坏生成器与输出的可复现关系。明确新增的是审查脚本，页面未修改。
