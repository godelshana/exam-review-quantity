# 真题已实际接入练习页面

本版不再使用旧的“40题待核入口”或“147题小池”替代整个真题库。

## 素材与用途

- 国考：现有400条卷内题位，逐条独立分析。
- 省考：66套原始卷、855条卷内出现记录，按粉笔题目ID去重后705题。覆盖安徽、广东、湖北、河南、四川；联考同题保留全部来源，不因去重丢失地区入口。
- **仅2024、2025、2026年国考及广东省考留作测试**。广东三年各15题，共45题，材料本来就在项目中，先前称缺资料是错误的。
- 其他年份国考、广东，以及其他省份各年真题，审核无实质问题的都用于训练。相同考点 / 方法家族只是抽题时的多样性参考，不是批量拒收理由。

## 页面怎么用

默认“真题梯度训练”，五题一轮。地区、考点、难度可筛选。展开“题库目录”可分页查看、指定单题练习；每题都有难度理由、自己的省步思路、常规解法、适用边界、易错点和独立核验。

有来源争议的题可在研读区对照推理，不把机构回忆答案称为官方答案。真的缺题干、数据矛盾或误抓到非数量题，逐条说明证据；不能把尚未审计的题包装成缺资料。

## 可复现的数据链

`full_audit/intake.json` → 12个分片 → `reviews/*.json` → `build_full_bank.py` → `full_audit/banks.js` → `app.js`。

- 输入题面、机构原标记与来源均保留；修复题面需在逐题记录说明原图 / 原卷依据。
- 图片由 `prepare_full_assets.py --import-local` 从本地原文件生成白底PNG发布副本，包含Brotli封装的恢复；原图不改。`asset_map.json` 记录原文件哈希与发布副本哈希。
- 默认离线构建仅需要已提交快照、审核记录和发布图片，不依赖未跟踪原始PDF库，也不联网。
- `build_full_intake.py --check --verify-local` 可在有原始资料的本机核对全部855条省考出现记录及400条国考快照。
- 当前实际数量见 `full_audit/summary.json`，逐题完整元数据见 `catalog.json`。旧 `datasets/` 仅保留上一版研究快照与GLM补充规则，不再决定真题是否入库。
