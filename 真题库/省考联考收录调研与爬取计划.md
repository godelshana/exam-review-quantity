# 省考/联考真题收录调研与爬取计划（粉笔）

> 目标：把题库从"国考 2011–2026"扩展到"国考 + 合适省考/联考近 15 年"，
> 优先服务数量关系刷题。原则：**难度 ≈ 或低于国考；广东省考必收；排除江苏系极难卷**。
> 调研日期：2026-09-10。

## 一、难度梯队结论（行测/数量关系）

| 梯队 | 省份 | 结论 |
|---|---|---|
| 高于/异于国考 | 江苏（数量 20 题且难、行测 135 题）、上海（多选题制）、陕西（不定项选择） | **排除** |
| 偏难 | 北京、天津、山东、浙江（题量大、竞争卷偏难） | **排除** |
| ≈ 或低于国考 | **联考省份**（河南、湖北、湖南、安徽、江西、福建、广西、云南、贵州、河北、山西、内蒙古、辽宁、吉林、黑龙江、重庆、甘肃、宁夏、青海、新疆、海南等，2025 年联考规模 24 地区） | **收录**（联考卷整体难度低于国考，数量关系以基础题型为主，10–15 题/卷） |
| 友好且必收 | **广东**（行测 90–100 题，数量关系 15 题 = 数字推理 5 + 数学运算 10；县级/乡镇分卷；难度梯度分明但整体低于国考） | **主力收录** |

> 广东附注：数字推理是国考没有的题型，但正好当"数字敏感"特训材料并入速刷体系，
> 不算超纲成本，算增量收益。

## 二、收录清单（年份窗口与国考库对齐：2011–2026）

| 优先级 | 卷 | 年份 | 预期卷数 | 预期数量关系题量 |
|---|---|---|---|---|
| P0 | 广东省考·县级卷 | 2011–2026 | ~15 | ~225（含数字推理 ~75） |
| P0 | 广东省考·乡镇卷 | 2011–2026 | ~13 | ~180（早年可能无乡镇卷，以粉笔卷目为准） |
| P1 | 联考代表：湖北 | 2011–2026 | ~14 | ~170 |
| P1 | 联考代表：河南 | 2011–2026 | ~14 | ~190 |
| P2 | 联考代表：安徽（或四川） | 2013–2026 | ~12 | ~150 |
| P3 | 补充：福建、云南、河北 | 视前述去重情况 | — | — |

- 联考卷跨省大半相同，**每个联考梯队只收 2–3 省做代表**，其余不重复收。
- 预期新增（去重前）~850 题；跨省去重后预计净增 **600+ 道**数量关系真题。

## 三、风险与对策

1. **联考卷跨省重复** → 以题干指纹去重（复用 integrate_fenbi 的 norm 思路）。
2. **数字推理超出国考数量大纲** → 单独归类"数字推理"，并入速刷页"数字敏感"线。
3. **早年卷粉笔可能缺失或回忆质量差** → 逐卷质检：题面残缺/答案缺失的整卷或单题标 `？`，不硬收。
4. **省考卷种命名杂**（A/B 卷、县级/乡镇、通用卷）→ 以粉笔卷目原名登记，卷种字段原样保留。

## 四、爬取方案（用户登录粉笔后执行）

现有管线（复用，不新造轮子）：
- `_downloads/fb_server.py`：本地 127.0.0.1:8765 接收浏览器控制台 POST 的 JSON；
- 粉笔 API 面（见 `_downloads/fenbi_ref.py`）：`/api/xingce/subLabels` 取省分类 →
  `/api/xingce/papers/?labelId=` 取卷目列表 → 建 exercise → 拉 questions（含正确答案）。

执行步骤：
1. 登录后按上表逐省逐年拉卷，存 `fb/paper_省_年_卷种.json`；
2. 新写 `_downloads/integrate_province.py`：归一化为 `fenbi_papers.json` 同构格式；
3. 题库侧新增 `真题库/按模块/06_省考联考/`（不手改现有脚本产物，走 `_downloads` 数据源流程扩展 assemble）；
4. 质检：跨省去重 + 缺答案标 `？` + 数字推理单独归类；
5. 广东卷优先爬（P0），每爬完一省停下来做一轮质检再继续。
