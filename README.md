# 公务员考试复习项目

本项目用于**利用历年真题复习公务员考试（国考）**。

## 快速开始

1. 打开 [真题库/README.md](真题库/README.md) 查看真题覆盖情况总表。
2. **从数量关系开始复习**：打开 [真题库/按模块/01_数量关系/00_使用说明与考点索引.md](真题库/按模块/01_数量关系/00_使用说明与考点索引.md)，
   按「摸底 → 考点分类突破 → 套卷模考 → 错题本」的流程刷完 2011–2026 年 400 道数量关系真题。
3. 套卷模考用 [真题库/按年份/](真题库/按年份) 下的完整试卷。

## 目录

- `真题库/` —— 2011–2026 年国考行测+申论真题（Markdown 整理版 + 原始PDF）
- `_downloads/` —— 真题抓取与解析的工作脚本及原始网页（可删除，删除后不影响真题库使用）

## 数据说明

所有真题均为考生回忆版（官方不公布），答案为各机构解析；详细的来源致谢、覆盖矩阵与已知缺口见 [真题库/README.md](真题库/README.md)。
